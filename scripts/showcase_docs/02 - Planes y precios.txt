INTELLIX — PLANES Y PRECIOS

1. Planes

¿Qué planes ofrece Intellix?
Intellix tiene tres planes: Starter, Profesional y Enterprise. Todos incluyen el asistente, la base de conocimiento, el panel de administración y el aislamiento completo de datos por organización.

¿Qué incluye el plan Starter?
El plan Starter incluye el widget web, hasta 50 documentos en la base de conocimiento, 2 operadores, 1 sector y hasta 2.000 consultas por mes. Cuesta 149 dólares por mes.

¿Qué incluye el plan Profesional?
El plan Profesional incluye el widget web y el canal de WhatsApp, hasta 300 documentos, 10 operadores, sectores ilimitados, personalidades adicionales, exportación de conversaciones y hasta 10.000 consultas por mes. Cuesta 390 dólares por mes.

¿Qué incluye el plan Enterprise?
El plan Enterprise es a medida: documentos y operadores sin límite, múltiples líneas de WhatsApp, acuerdo de nivel de servicio, soporte prioritario, acompañamiento de onboarding y opciones de integración con sistemas propios. El precio se define según el volumen de consultas y los canales.

2. Consultas y volumen

¿Qué se considera una consulta?
Cada mensaje de un usuario que el asistente responde cuenta como una consulta. Los mensajes atendidos por un operador humano no cuentan. Las respuestas servidas desde el cache tampoco cuentan para el límite mensual.

¿Qué pasa si supero el límite de consultas del plan?
El asistente sigue respondiendo. Al superar el límite, el administrador recibe un aviso por correo y el equipo comercial se comunica para ajustar el plan. No se corta el servicio sin aviso.

3. Contratación y facturación

¿Hay período de prueba?
Sí. Todos los planes tienen 14 días de prueba sin cargo, con todas las funciones del plan Profesional habilitadas. No se pide tarjeta para empezar.

¿Cómo se factura?
La facturación es mensual, por adelantado. Se puede pagar con tarjeta de crédito o transferencia bancaria. Para organizaciones de Argentina se emite factura A o B según corresponda.

¿Puedo cambiar de plan?
Sí, en cualquier momento. Al subir de plan las funciones nuevas quedan disponibles de inmediato; al bajar, el cambio aplica desde el siguiente período de facturación.

¿Cómo contrato?
Escribinos desde el chat o a ventas@intellix.com.ar. Un integrante del equipo comercial coordina una demo de 30 minutos y deja la organización configurada el mismo día.
